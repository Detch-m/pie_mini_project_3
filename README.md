# PIE MP3
By Thanadetch (Detch) Mateedunsatits and Kiran Collins

We created a giant technoblade design. To reproduce the Technoblade check the CAD_Models files, specifically search for [Fullbody_DFM.SLDASM](https://github.com/Detch-m/pie_mini_project_3/blob/main/CAD_Models/Fullbody_DFM.SLDASM) and download each of the body components (Torso, Arms, Legs, and Head). These components need to be laser cut.

Additionally, the skin of the Technoblade can be found in [TechnobladeSkinPrintout](https://github.com/Detch-m/pie_mini_project_3/tree/main/TechnobladeSkinPrintout)
